# Assets Directory

This directory contains all static assets for the Wedding Planning System.

## Structure

### diagrams/
Contains system diagrams and visual documentation:

- **er-diagram.svg** - Entity-Relationship diagram (SVG format)
- **er-diagram.png** - Entity-Relationship diagram (PNG format)

## Diagram Information

### ER Diagram
- **Purpose**: Database architecture visualization
- **Format**: Mermaid ER diagram
- **Related Documentation**: `backend/docs/ER-Diagram.md`
- **Created**: April 22, 2026
- **Version**: 1.0

## Usage

### Viewing the Diagrams
- **SVG**: Best for web viewing and scalability
- **PNG**: Best for documents and presentations

### Integration
The diagrams are referenced in the documentation:
- ER Diagram markdown file includes relative paths to these assets
- Can be embedded in README files and documentation

## File Naming Convention

- Use kebab-case for file names
- Include descriptive names (e.g., `er-diagram` instead of timestamps)
- Provide multiple formats when applicable (SVG, PNG)
